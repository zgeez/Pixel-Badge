# Classic bitmap font

Printable ASCII subset (32–126) of Adafruit GFX glcdfont.c.
Five columns per glyph, eight rows, least significant bit at the top.
Lowercase and punctuation retain their shapes. The same table is used by
the portable firmware renderer and Flutter preview.

Source: https://github.com/adafruit/Adafruit-GFX-Library/blob/master/glcdfont.c
