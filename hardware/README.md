# Hardware

KiCad 10.0.6 design files for the badge PCB. No design files exist yet; see
[docs/hardware.md](../docs/hardware.md) for the provisional architecture.

## Layout

| Path | Contents |
|---|---|
| `libraries/symbols/` | Project schematic symbol libraries (`.kicad_sym`) |
| `libraries/footprints/` | Project footprint libraries (`.pretty/`) |
| `libraries/3dmodels/` | 3D models referenced by project footprints |
| `mechanical/` | Mechanical drawings and enclosure/mount sources |

Project libraries should be referenced through project-relative library tables
so the design opens on any machine without local path changes.

## Generated outputs

Gerbers, drill files, BOM, placement files, schematic PDFs, and STEP exports are
generated by CI or at release time and published as release assets. They are not
committed.

## Rules

- Verify footprint pin numbering and polarity against the manufacturer
  datasheet; never assume it.
- Do not suppress ERC/DRC violations without a documented rationale.
- Keep SWD access and power test points on Rev A.
